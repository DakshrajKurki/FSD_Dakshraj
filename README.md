## Pages

| Category | Files | What I practised |
|---|---|---|
| **HTML & layout** | `Syntax.html`, `flag.html`, `navbar.html`, `time table.html`, `Resume.html` | Page structure, tables, flexbox navbar, CSS shapes (Indian flag) |
| **Forms** | `Forms.html`, `Travel_reg_form.html`, `alliance.html`, `Facebook.html`, `instagram.html` | Inputs, fieldsets, selects, validation attributes, recreating common login/sign-up layouts |
| **Responsive design** | `RWD.html`, `CSV_Grid_style.css` | Media queries, CSS Grid |
| **JavaScript** | `basics of js.html`, `details of daksh.html`, `calculator.html` | Variables, DOM output, a working calculator |

## View them

Clone the repo and open any `.html` file in your browser — no build step needed.
